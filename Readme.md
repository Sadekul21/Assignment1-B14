DEVCONF 2026 presents a modern conference experience with a hero section, speaker profiles, pricing plans, FAQ, registration buttons, and a clean responsive layout.

## 📖 About the Project

DEVCONF 2026 is a responsive front-end conference website created using **HTML and CSS**.

The website is designed to present conference information in a simple and organized way, including speakers, ticket pricing, registration options, and frequently asked questions.

---

## ✨ Features

- Responsive navigation bar
- Full-width hero section
- Speaker profile cards
- Conference pricing plans
- Registration call-to-action buttons
- FAQ section
- Clean and structured layout
- Responsive design for different screen sizes

---

- Git

- GitHub Pages

---

## 🏠 Main Sections

### Hero Section
Introduces the conference with the main message:

**Code. Connect. Create.**

Includes event information and a registration button.

### Speakers Section
Displays featured conference speakers with their images, names, and tracks.

### Pricing Section
Includes three ticket options:

- Standard
- Pro
- Team

### FAQ Section
Provides answers to common questions about tickets, pricing, upgrades, and the event.
